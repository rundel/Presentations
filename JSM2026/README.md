# Automate all the things

Teaching modern data science and statistics courses presents numerous logistical challenges — from building and distributing assignments and other course materials to providing timely, consistent feedback. In this talk, we explore tools for automating the repetitive aspects of course administration, building on the core reproducible infrastructure of Git, GitHub, and Quarto. Examples will include the ghclass package, which streamlines classroom management on GitHub, enabling automated repository creation, assignment distribution, and collection. GitHub Actions, which extends this ecosystem with CI pipelines that automatically render documents, run checks, and provide feedback on student submissions. The parsermd and markrmd packages, which offer programmatic tools for parsing and manipulating R Markdown and Quarto documents, enabling both automated and more efficient manual assessment of student work. Finally, we look ahead to the emerging role of agentic AI tools in teaching, discussing both the opportunities and considerations for AI-driven automation in course management.
